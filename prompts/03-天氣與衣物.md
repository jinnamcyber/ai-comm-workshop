# 天氣與衣物

## 老師原本嘅諗法
「觀察天氣，選衣物並練習表達。」（全科；想做供教師操作嘅互動教具）

## ❌ 無效講法
幫我做一個天氣同衣服嘅教具畀小朋友。

## ✅ 有效講法（可以直接貼入 Gemini Canvas）
```
你係一位澳門幼兒高班至小一嘅老師，我想你幫我寫一個「天氣與衣物」互動教具，用喺電子白板（觸控、16:9、1920×1080）上課，由老師操作、全班一齊睇。

【目的】
讓學生觀察天氣，學識按天氣揀合適嘅衣物，並練習用完整句子表達：「今日天氣＿＿，我會著＿＿同＿＿，因為＿＿。」

【形式】
單一 HTML 檔（HTML + CSS + JavaScript 全部放喺同一個檔），可以離線打開，唔好用任何外部圖片、字型或 CDN。畫面分三欄：
1. 左邊係大窗口天氣場景（用 SVG 動畫畫）：晴天（太陽慢慢轉、白雲飄）、落雨（雨點落下、地下有水窪漣漪）、寒冷（雪花飄落、有雪人同寒風線條）、炎熱（大太陽戴太陽眼鏡、流汗、熱浪）、大風（樹搖動、樹葉同風箏飛）。窗口下面有五個大掣揀天氣，另外有一個「🎲 隨機天氣」掣。天氣轉換要平滑（淡入淡出），場景右上角顯示天氣名同氣溫。
2. 中間係一個可愛、中性嘅 SVG 小朋友（正面全身，內裡著簡單內衣）。
3. 右邊係衣物櫃，3 欄格仔，每件衣物有 SVG 圖示同名稱：短袖衫、長袖衫、外套、羽絨、短褲、長褲、雨褸、雨遮、太陽帽、冷帽、頸巾、涼鞋、水靴、波鞋，另加一個「全部脫低」掣。點選或者拖放到小朋友身上就會著上（用 SVG 圖層疊加，位置要啱，同一部位只可以著一件，例如揀咗羽絨就會取代外套），再點一次就脫下。

底部一行有兩個大掣：
- 「✅ 檢查」：按當前天氣判斷衣物合適與否。唔合適就顯示黃色溫和提示（例如「落雨喎，記得帶遮或者著雨褸」、「好凍喎，短褲會凍親，換長褲啦」），小朋友表情同步變化（流汗、發抖、擔心）；合適就顯示綠色鼓勵、小朋友跳一跳，並加一聲「叮」（用 Web Audio 合成，唔好用音檔）。仲未著上衣、褲或者鞋，要先提示補齊。
- 「🗣️ 講一講」：自動生成句子框「今日天氣＿＿，我會著＿＿同＿＿，因為＿＿。」，用已穿衣物同當前天氣填好，填入嘅詞語用顏色底線標示；然後用 speechSynthesis 以 zh-HK 廣東話聲線逐句朗讀，朗讀緊嗰句高亮，小朋友嘴巴會郁；讀完提示「輪到你喇！跟住讀一次」。提供「🔊 再聽一次」同「🐢 慢速」掣。揀聲線時先揀 zh-HK，冇就用 zh 開頭，冇聲線都唔可以出錯。

【限制】
- 全部文字用繁體中文（香港／澳門用字），字號至少 24px，所有掣高度至少 64px，用 pointer events 令觸控同滑鼠都用得，唔好靠 hover，唔好用 alert()。
- 色調：暖米色背景、白色大圓角卡片、掣有厚底影（似可以撳落去）；插圖用扁平、粗線條、圓角嘅 SVG，唔好用 emoji 做主要插圖。
- 版面喺 1280×720 至 1920×1080 都要好睇，唔好出現橫向捲動。
- 頂部標題列：左邊科目標籤「全科」＋教具名，右邊「⛶ 全螢幕」同「↺ 重新開始」。右下角細字「AI 輔助備課工作坊 · 示範教具」。
- 答錯用黃色提示，唔好用大紅交叉。
- 唔好有 console error，JS 要做 null check。

【回饋】
我之後會試用，再告訴你邊度要改。
```

## 🔁 第二輪回饋示範
1. 「衣物櫃啲圖示太細，坐喺課室後面睇唔清楚；請將圖示放大約 1.5 倍，名稱字體加粗。」
2. 「檢查嘅提示一次出晒四五句，學生讀唔切；改成最多出兩句，每句唔好超過 15 個字，而且最重要嗰句擺最前。」
3. 「講一講個句子，『因為』後面成日係『我想著得舒服』；請按已穿嗰件衣物嘅功能寫原因，例如『因為雨遮可以擋雨』。」

## 💡 課堂用法
- **導入觀察**：老師撳「🎲 隨機天氣」，叫學生睇窗外場景同氣溫，先講「今日天氣好熱／好凍」，再叫一位同學上嚟揀衫。
- **分組討論**：同一個天氣，叫兩組揀唔同衣物，撳「✅ 檢查」睇提示，討論點解要改（例如落雨點解要帶遮）。
- **口語跟讀**：揀好衫後撳「🗣️ 講一講」，全班跟讀句子；撳「🐢」慢速俾初階學生跟，再邀請學生自己用句子框講一次。
