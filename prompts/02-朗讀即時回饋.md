# 朗讀即時回饋

## 老師原本嘅諗法
「朗讀後，系統自動給予即時回饋」（中文科，語基；想做供學生操作的互動活動）

## ❌ 無效講法
幫我做一個朗讀練習，學生讀完會有回饋。

## ✅ 有效講法（可以直接貼入 Gemini Canvas）
你是一位小學中文科的教學設計助手。請為小二至小三學生（澳門學校，使用繁體中文）製作一個「朗讀即時回饋」的互動網頁，在電子白板和電腦上都能使用。

目的：學生朗讀後，系統立即逐字比對，讓學生知道哪些字讀對、哪些字需要再練習。

形式：
1. 單一 HTML 檔，所有 CSS、JavaScript、插圖都內嵌，不使用任何外部資源，可離線雙擊打開。
2. 三個關卡：第一關詞語（6 個，例如蘋果、小貓、朋友）、第二關短句（4 句）、第三關短段落（1 段，約 40 字）。內容要正面、生活化。
3. 每題有「🔊 示範」按鈕（用 speechSynthesis，lang 為 zh-HK，找不到聲線也不能出錯）和「🎤 開始朗讀」按鈕（用 SpeechRecognition / webkitSpeechRecognition，lang 先用 yue-Hant-HK，並提供小設定按鈕切換 zh-HK / zh-TW）。
4. 朗讀後逐字比對，忽略標點，用一個小對照表處理常見簡繁差異。讀對的字顯示綠色，漏讀或讀錯的字用黃色底（不要用紅色叉叉）。顯示準確率百分比和一句鼓勵的話，並有「再讀一次」按鈕。
5. 錄音時要有明顯的動畫（咪高峰脈動、聲波）。
6. 後備方案：如果瀏覽器不支援語音辨識，或出現 not-allowed、network 等錯誤，不要壞掉，要顯示清楚提示「語音辨識需要 Chrome / Edge 同網絡；可以用 http://localhost 打開」，並提供「老師評分模式」：老師直接點擊讀錯的字標成黃色，得出同樣的準確率和回饋。

限制：
- 字號至少 24px，按鈕高度至少 64px，支援觸控；不使用 alert()。
- 頂部有標題列（科目標籤＋教具名稱，右邊有「全螢幕」和「重新開始」），右下角小字「AI 輔助備課工作坊 · 示範教具」。
- 配色：暖米色背景、白色大圓角卡片、實色按鈕；插圖用內嵌 SVG 畫一隻可愛的小雞吉祥物，錄音時會搖擺，讀得好時會跳起來。

回饋：答對用綠色加小動畫和一聲「叮」（用 Web Audio 合成，不用音檔）；讀得不理想時語氣要溫和，鼓勵學生再試。

## 🔁 第二輪回饋示範
1. 短段落那一關的字太細，請把字號放大約 20%，行距加闊，白板後排的學生也要看得清楚。
2. 準確率低於 60% 時，不要只說「再試一次」，請加一句具體提示，例如「先按示範，慢慢聽一次，再讀黃色的字」。
3. 黃色的字請改成可以點一下就讀出該字的讀音，讓學生可以單獨練習。

## 💡 課堂用法
- 老師用電子白板開啟，先按「🔊 示範」帶讀，再請學生輪流上台按「🎤 開始朗讀」，全班一起看哪些字是黃色。
- 如果課室網絡不穩或瀏覽器不支援語音辨識，改用「老師評分模式」：學生朗讀，老師點擊讀錯的字，一樣可以得到即時回饋。
- 讓學生比較兩次朗讀的準確率，鼓勵他們針對黃色的字練習，作為課堂上的小目標。
