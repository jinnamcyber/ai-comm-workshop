# 音樂聽辨
## 老師原本嘅諗法
資訊科技、音樂老師想做「配合某個課題的課堂活動」：
「老師提問題題，學生點選圖示或動畫選項」

## ❌ 無效講法
幫我做一個音樂遊戲，叫學生聽聲音答問題。

## ✅ 有效講法（可以直接貼入 Gemini Canvas）
你係一位小學音樂科老師，我教小一至小三（6 至 9 歲），學生識字量有限，請幫我做一個課堂用嘅互動網頁教具「音樂聽辨」，會喺電子白板（觸控、16:9）上用。

【目的】訓練學生辨別音樂基本要素。四類題目，可以揀單一類別或者混合：
1. 高音／低音（小鳥 vs 大象）
2. 快／慢（兔仔 vs 烏龜）
3. 強／弱（獅子 vs 老鼠）
4. 上行／下行旋律（爬樓梯向上 vs 落樓梯）

【形式】
- 單一 HTML 檔，CSS、JS、SVG 全部內嵌，唔好用外部圖片、字型或音檔，要可以離線打開。
- 聲音全部用 Web Audio API 即時合成：oscillator ＋ gain 包絡（ADSR）＋低通濾波；旋律只用五聲音階（宮商角徵羽），音色柔和、唔好刺耳；強弱用音量差異，快慢用速度差異，高低用音域差異，上下行用五個音級進。
- 老師撳「▶ 播放」播出一個聲音，學生聽完點選兩張大卡其中一張作答。每張卡有自己畫嘅 SVG 動物或者圖示（扁平、粗線條、童趣），播放同點選時有對應動畫：小鳥拍翼、大象搖鼻、兔仔跳、烏龜慢慢爬、獅子張口吼、老鼠發抖、小人行上／落樓梯。
- 播放題目聲音時唔好動畫目標卡，以免提示咗答案；改用聲音跳動條顯示。

【限制】
- 全部繁體中文（香港用字），字號不小於 24px，按鈕不小於 64px 高；用 pointer／click 事件，唔好靠 hover，唔好用 alert()。
- 顏色：暖米色背景、白色大圓角卡片、按鈕有厚底影；答錯唔好用大紅交叉，改用黃色提示。
- 10 題一輪，右上角用星星計分（第一次答啱先有星）。另外有「老師模式」：唔計分，只有播放、「兩個一齊聽」同「揭曉答案」，方便全班一齊答。

【回饋】
- 答啱：該動物跳舞＋閃爍星星＋合成「叮」聲，並用一句講解（例如「高音，好似小鳥吱吱叫」）。
- 答錯：卡片轉黃色＋溫和提示句，同時自動依次播放兩個對比聲音（左邊再右邊，播緊邊個邊張卡就動），可以再答。
- 另有「再聽一次」同「讀題」（speechSynthesis，zh-HK 聲線，冇聲線都唔可以出錯）。
- 完成十題後顯示星星成績同「再玩一輪」「揀其他類別」。

## 🔁 第二輪回饋示範
1. 「弱」嗰個聲音喺課室太細聲，聽唔清：請將弱音量加大少少（但仍然要明顯比強音細），並喺畫面加一句「請將喇叭音量調到中等」。
2. 小一學生未必識字，請喺每張卡嘅動物下面加一個細喇叭掣，撳一下就用廣東話讀出「高音」「小鳥」等字。
3. 答錯之後唔好即刻自動播對比，改成出現一個黃色「聽聽比較」按鈕，由老師決定幾時播。

## 💡 課堂用法
- 導入新課題（例如「音的高低」）時，用老師模式全班一齊聽，叫同學舉左手／右手揀答案，再揭曉；每個概念玩一至兩輪。
- 小組活動：每組一部平板，用學生模式比賽誰先得 8 粒星以上。
- 課後延伸：叫學生自己用拍手、嗓音模仿「小鳥聲」同「大象聲」，再同合成聲音比較。
