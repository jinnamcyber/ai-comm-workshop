# 植物的組成（互動教具）

## 老師原本嘅諗法
常識科，植物的生長及組成；想做「供學生操作的互動活動」：
「學生按指示點選植物的各個組成部分、可以點選後看到植物成長過程動畫」

## ❌ 無效講法
幫我做一個關於植物嘅互動遊戲畀學生玩。

## ✅ 有效講法（可以直接貼入 Gemini Canvas）
```
你係一位資深嘅網頁互動教具設計師。我係澳門一間小學嘅常識科老師，對象係小三學生（8-9歲），單元係「植物的生長及組成」。

【目的】
令學生認識植物嘅五個組成部分（根、莖、葉、花、果實）同佢哋嘅功能，並了解植物由種子長成嘅過程。

【形式】
請用 Canvas 做一個單一 HTML 檔嘅互動網頁（所有 CSS、JS、SVG 都內嵌，唔好用外部圖片、字型或 CDN），分頂部三個大分頁：
1. 「認識」：用 SVG 畫一棵扁平、童趣、粗線條嘅植物（有根、莖、葉、花、果實，根部要用泥土橫切面睇到）。學生點每個部分，該部分會發光，彈出名稱同一句小三程度嘅功能解釋，並用 speechSynthesis（zh-HK 廣東話）讀出。
2. 「挑戰」：系統隨機出題「請點選：葉」（同時讀出），學生點圖作答。答啱：該部分變綠色發光＋「叮」一聲（用 Web Audio 合成，唔好用音檔）。答錯：用黃色柔和提示，並畀線索（例如「葉通常係綠色、扁扁的，長喺莖上」），唔好用紅色交叉。一輪 5 題，用 5 粒星做進度，完結時顯示成績。
3. 「成長」：播放「種子→發芽→幼苗→長葉→開花→結果」嘅動畫，SVG 逐步平滑變化，有播放／暫停掣、一條可以拖動嘅時間軸，每個階段有字幕。

【限制】
- 繁體中文（香港／澳門用字），朗讀用 zh-HK。
- 白板使用：基本字號 24px 或以上，所有可點區域至少 64px 高，用 pointer events，唔好靠 hover，唔好用 alert()。
- 頂部標題列：左邊「常識科」標籤＋教具名稱，右邊「全螢幕」同「重新開始」掣；右下角細字頁腳。
- 版面固定 16:9，喺 1280×720 至 1920×1080 都要好睇；顏色用暖米色背景、白色大圓角卡片、實色按鈕＋底部厚陰影。
- 冇聲線時唔可以 crash，唔好有 console error。

【之後點樣回饋】
我睇完第一版之後會逐項講邊度要改（字體大細、提示字句、動畫速度），請你只改我指出嘅部分，其他保持不變。
```

## 🔁 第二輪回饋示範
1. 「挑戰」模式答錯嘅提示太籠統。請每個部分寫一句更具體嘅線索，例如「根」要提到「喺泥土入面、幼幼長長」，「果實」要提到「入面有種子」。
2. 「成長」動畫嘅字幕字體太細，白板後排睇唔到，請放大到至少 28px，並將每個階段嘅時間由 2 秒增加到 4 秒。
3. 時間軸下面加六個階段掣（種子、發芽、幼苗、長葉、開花、結果），撳一下可以直接跳到該階段。

## 💡 課堂用法
- 「認識」模式用電子白板全班一齊玩：請學生上前點植物，其他同學先估名稱同功能，再睇系統答案。
- 「挑戰」模式分組比賽，每組輪流答一題，睇邊組攞到最多金星；答錯嘅線索可以請同學先讀出嚟再答。
- 「成長」模式先暫停喺每個階段，問學生「下一步會發生乜事？」，估完先繼續播放；之後可叫學生用自己種嘅豆苗對照。
