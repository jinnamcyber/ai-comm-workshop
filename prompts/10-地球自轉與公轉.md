# 地球自轉與公轉

## 老師原本嘅諗法
課題：「地球自轉和圍繞太陽公轉」。問卷選項中，老師想要「供教師操作的互動教具，例如互動地圖或可調整數值的示範」。

## ❌ 無效講法
```
幫我做一個地球繞太陽轉的動畫。
```

## ✅ 有效講法（可以直接貼入 Gemini Canvas）
```
我是澳門一間中小學的常識科老師，任教小五、小六。我想在電子白板（觸控、16:9）上，向全班示範「地球自轉和圍繞太陽公轉」，請幫我用 Canvas 做一個單一 HTML 檔的互動教具（所有 CSS／JS 內嵌，不要用任何外部連結，離線可開）。

【目的】
讓學生看見：1）自轉造成日夜；2）公轉加上「地軸傾斜 23.5°」造成四季和日長夜短的變化。

【形式與內容】
1. 主畫面：太陽在中間，地球沿近乎圓形的軌道公轉，用 2.5D 斜視角畫。地球有日夜分界（向太陽的一面明亮，背面較暗）。地軸傾斜 23.5°，而且傾斜方向在整個公轉過程中固定指向同一方向（這點科學上一定要正確）。
2. 控制區：播放／暫停；速度滑桿；「自轉」開關；「公轉」開關；日期滑桿（1 至 12 月，拖動時地球移到相應位置）。
3. 標記：在軌道上標出春分、夏至、秋分、冬至四個位置（附日期，點擊可跳到該日）。標出澳門的位置點（北緯約 22°）。拖到不同月份時，側邊資訊卡顯示澳門當時大約的季節，以及「日長夜短／日短夜長」和白晝大約幾多小時。
4. 側邊放大圖：地球近鏡（自轉中），能看見澳門那個點由白天轉入黑夜，並顯示「一日 = 自轉一圈 ≈ 24 小時」「一年 = 公轉一圈 ≈ 365 天」。
5. 教學提問卡：3 張可翻轉的卡（正面問題、背面答案），例如「如果地軸沒有傾斜，會不會有四季？」，並提供「地軸無傾斜」切換掣，方便做對比。

【限制】
- 對象是小學生：繁體中文（香港／澳門用字），句子短，不用太深的術語。
- 白板友善：字體不少於 24px，按鈕不少於 64px 高，不要依賴滑鼠 hover，用 pointer events 令觸控和滑鼠都能操作。
- 版面在 1280×720 至 1920×1080 都好看；所有插圖用內嵌 SVG／Canvas 自己畫，不用外部圖片。
- 科學要準確：地軸傾斜方向固定、夏至時北半球向太陽傾斜；若有為了畫面而簡化的地方，請在畫面上註明「示意」。
- 配色：暖米色背景、白色大圓角卡片、實色按鈕。
- 不要用 alert()，不要有 console error。

請先給我完整可運行的程式碼，不用逐行解釋。
```

## 🔁 第二輪回饋示範
1. 「地軸那條線和『北』字太細，坐在最後排的學生看不清，請加粗，並加上『23.5°』的角度弧線標示。」
2. 「夏至時，請在資訊卡加一句『北半球向太陽傾斜，陽光較直、白晝較長』；冬至則顯示相反的說法。另外，春分和秋分要寫明『晝夜幾乎一樣長』。」
3. 「放大圖的日夜分界太模糊，請令黑夜部分更暗；澳門的點要大一點，並顯示『白天／黑夜』標籤；速度太快時，請提示『自轉只作示意』。」

## 💡 課堂用法
1. **先問後示範**：先問學生「為甚麼會有白天黑夜？」，開啟「自轉」、關閉「公轉」，把速度調慢，看澳門的點由白天轉入黑夜；再問「為甚麼會有四季？」，關閉自轉，拖動日期滑桿，看夏至和冬至的日長變化。
2. **做對比實驗**：按「地軸無傾斜」，再拖動一年，讓學生發現全年日夜一樣長，再翻開提問卡 1 核對答案，建立「四季來自地軸傾斜」的概念。
3. **破解迷思**：用提問卡 2（地球離太陽最近是夏天嗎？）和提問卡 3（澳門夏天，澳洲是甚麼季節？）討論常見迷思，再讓學生上台拖動日期驗證。
